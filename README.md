# Comfy Floor Map

Неофіційний особистий тренажер для менеджера-консультанта **Comfy**: карта залу, каталог, цінові полиці, хіти, порівняння і навчання по черзі.

> Це не офіційний продукт Comfy і не заміна Digital Assistant.

Повне ТЗ: [TZ.md](./TZ.md)

## Що вміє

- Карта всього залу (департаменти → секції)
- **Каталог** з фільтрами: секція / полиця / бренд / хіти / пошук
- У кожній секції: бюджет / середній / преміум + тренажер
- Порівняння 2–3 моделей, сценарії «Клиент сказав…», повторення слабких
- Темна тема в тонах Comfy

## Запуск

```bash
npm install
npm run dev
```

Відкрий http://127.0.0.1:43127

## Каталог і парсер

Навчальний seed (сотні позицій) уже всередині:

```bash
npm run seed:catalog
```

Live-парсер публічних сторінок comfy.ua (краще з твого WSL/домашнього IP; хмарні IP часто блокує Cloudflare):

```bash
npm run parse:comfy
```

Після успішного парсу з’явиться `src/content/catalog-live.ts` — перезапусти `npm run dev`.

Парсер ввічливий (пауза ~2.5 с між категоріями), без `/api/`, лише категорійні сторінки.

## Структура

- `src/content` — секції, seed/live каталог, тренажер
- `src/app` — сторінки (каталог, секції, тренажер, порівняння…)
- `scripts/seed-catalog.mjs` — генерація навчального каталогу
- `scripts/parse-comfy.mjs` — локальний парсер Comfy
