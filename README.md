# Comfy Floor Map

Неофіційний особистий тренажер для менеджера-консультанта **Comfy**: карта залу, цінові полиці, хіти, порівняння характеристик і навчання по черзі.

> Це не офіційний продукт Comfy і не заміна Digital Assistant.

Повне ТЗ: [TZ.md](./TZ.md)

## Що всередині

- Карта всього залу по департаментах і секціях
- У секції: бюджет / середній / преміум + хіти
- Картки моделей з «мовою продавця»
- Порівняння 2–3 моделей
- Режим «Клиент сказав…»
- Тренажер із прогресом у `localStorage`
- Темна тема в тонах Comfy (помаранчевий + зелений)

## Запуск локально

Потрібні Node.js 20+ і npm.

```bash
cd /шлях/до/проєкту
npm install
npm run dev -- --port 43127
```

Відкрий [http://127.0.0.1:43127](http://127.0.0.1:43127).

Інші команди:

```bash
npm run build
npm start -- --port 43127
```

## Структура

- `src/content` — секції, хіти, терміни, сценарії, кроки тренажера
- `src/app` — сторінки
- `src/components` — UI й клієнтські модулі
- `src/lib/progress.ts` — локальний прогрес навчання

## Примітка про дані

Контент MVP — навчальний скелет (лінійки/типи хітів і сценарії консультанта), не live-прайс і не повний каталог Comfy. Ціни вказані як коридори полиць.
