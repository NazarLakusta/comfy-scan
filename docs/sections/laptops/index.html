Головні характеристики

Словник секції — те, що пояснюєш клієнту простими словами.

8 vs 16 ГБ ОЗП

8 ГБ — мінімум для навчання. 16 ГБ — щоб Chrome + Zoom + документи не перетворювались на слайд-шоу.

SSD

Швидкий накопичувач. Ноут зі SSD вмикається й відкриває файли помітно швидше за старий HDD.

Вбудована vs дискретна відеокарта

Вбудована — офіс, навчання, серіали. Дискретна — ігри, монтаж, 3D. Не продавай ігрову «про запас».
